# Sistema Bancário em Python

Projeto desenvolvido em Python simulando um sistema bancário simples.

## Funcionalidades

- Cadastro de clientes
- Depósito
- Saque
- Extrato bancário
- Listagem de clientes

## Tecnologias utilizadas

- Python 3
- Estruturas de dados
- Funções
- Módulos

## Como executar

Clone o repositório:

git clone https://github.com/LauraSouzaa/sistema-bancario-python.git

Execute:

python main.py
